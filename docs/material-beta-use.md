# 소재사용량조사(Beta)

- 2026.11.06.12: 사이트 카운터(part_count)는 읽거나 비교하지 않고 신규 이력에도 저장하지 않습니다. 수량은 프로그램 번호 변화만으로 판단하며, 카운터의 증가·초기화·누락은 집계에 영향을 주지 않습니다. 9020 왕복 제외와 기존 재가공·불량·재고 규칙은 유지합니다. 기존 이력과 데이터 형식은 보존합니다.

- 새로 지정하는 소재는 Ø10 B급을 기본 선택합니다. 지정 후 새 봉으로 교체하면 B급 재고만 차감합니다. 이미 지정된 Z급·12파이·14파이와 다음 소재 예약은 유지하며, 다른 등급을 사용하려면 소재 설정에서 선택합니다.

- 지후니우스 상단 특수 돌출량 오른쪽 버튼으로 원래 크기의 팝업을 엽니다. 이미 열려 있어도 다시 누르면 앞에 표시합니다. X를 누르면 숨깁니다.
- 메인 화면 하단에는 1~9호기가 가로로 배치되며 각 호기 아래 ‘불량’과 ‘소재교체’가 있습니다. 불량은 기존대로 양품 1개를 불량으로 변경하고, 소재교체는 확인 후 실행합니다. 입력 중인 호기는 저장 결과 확인까지 잠깁니다.
- 메인·서브 모두 빠른 입력 연결을 위해 소재 프로그램을 숨김 상태로 함께 시작합니다. 수집 ON/OFF 설정은 바꾸지 않습니다. 메인 입력의 확인 대기 기록은 PC에 보관되고 재실행 시 같은 요청 번호로 확인하므로 중복 반영하지 않습니다.
- 기존 독립 소재카운터는 완전 종료한 뒤 통합 기능을 사용합니다. 배포본은 지후니우스의 기존 업데이트 경로로 설치합니다.
- 기존 소재 데이터가 있는 메인 PC에서 먼저 ‘이 PC 수집 ON’을 켭니다. 처음 ON을 켠 PC가 수집 담당으로 등록됩니다.
- 서브 PC는 OFF로 유지합니다. 같은 회사 공유 폴더의 연결 설정으로 담당 PC를 찾습니다. 별도 IP 입력은 없습니다.
- 담당 PC 및 지후니우스가 실행 중이어야 동기화합니다. 담당 PC의 팝업은 숨겨도 됩니다.
- 불량·소재교체·재고·취소는 담당 PC에서 저장 성공을 확인한 뒤 표시합니다. ‘저장 확인 대기’는 같은 작업을 다시 입력하지 않습니다.
- 연결이 끊겨 완전 종료할 때 확인 대기 입력을 유지하는 선택이 있습니다. 다음 실행에서 같은 요청 번호로 결과를 확인합니다.
- 기간 통계는 실제 조회 날짜·호기·조회 시각을 표시합니다. ‘새 기록 있음 / 조회 조건 변경’이면 다시 조회합니다.
- 현재 집계 안의 소재교체·불량 버튼은 제거하고 메인 하단의 입력 버튼을 사용합니다. 소재명 클릭으로 사용 소재·다음 소재를 지정하고 우클릭으로 마지막 입력을 취소하는 기능은 유지합니다.
- 현재집계 오른쪽의 호기별 한 버튼은 ‘14파이 교체’ ↔ ‘원소재로 복귀’로 바뀝니다. 14파이로 전환하면 원소재를 보관하고, 복귀하면 원소재의 기존 양품·불량을 이어갑니다. 복귀 시 뺀 14파이도 보관하므로 재전환 시 같은 봉을 재사용합니다. 사용 소재 아래에 보관 봉의 종류·양품·불량을 함께 표시합니다.
- 새 14파이 최초 투입만 재고 1봉을 차감합니다. 보관 봉 복귀는 재고를 차감하지 않고 사용 종료로 계산하지도 않습니다. 다 쓴 봉은 해당 봉이 장착된 상태에서 메인의 ‘소재교체’로 마감합니다. 14파이를 새 봉으로 교체해도 보관한 원소재는 유지됩니다.
- 원소재 보관 중에는 14파이 새 봉만 교체할 수 있습니다. 다른 소재로 새 봉을 바꾸려면 먼저 ‘원소재로 복귀’합니다. 보관한 14파이가 있는 경우 다음 소재로 14파이를 예약하는 대신 전환 버튼을 사용합니다.
- 잘못 누른 전환은 우클릭 취소가 가능합니다. 전환 후 가공·불량·소재 설정 기록이 생기거나 해당 재고를 실사 조정한 경우에는 기록을 섞지 않도록 취소를 막고 전환 버튼으로 복귀하게 합니다.
- 기간통계 날짜 옆의 월 선택·이전 달·다음 달과 ‘이번 달’은 해당 월 1일부터 말일까지 조회합니다. 날짜 직접 입력과 호기 선택도 유지합니다.
- 중도교체 버튼과 기간 통계의 중도파기 구분은 표시하지 않습니다. 적게 가공한 봉도 교체 시 소모 1봉에 포함하며 기존 중도교체 기록도 집계에 유지합니다. 중간 시작·수집 공백·불량초과 기록의 평균 제외 기준은 유지합니다.
- 기간 통계 상단에서 Ø10·Ø12·Ø14별 사용 봉 수를 확인합니다. Ø10은 Z급·B급의 합계와 각각의 수량을 함께 표시합니다. 선택한 날짜·호기의 사용 종료 봉 기준이며 사용 중인 봉은 교체 후 반영합니다.
- ‘모두 초기화’는 확인 후 가공·불량·교체·입출고 기록, 현재 집계, 재고 수량, 호기별 소재 설정을 모두 지웁니다. 재고는 0봉이 아닌 미등록 상태가 됩니다. 사용자 요청에 따라 초기화 전 자동 백업은 하지 않습니다. 필요하면 별도의 ‘전체 데이터 백업’을 먼저 사용합니다.
- 초기화는 모든 PC에 반영되고 이전 통계·기록 화면도 비웁니다. 과거 요청이 뒤늦게 도착해도 초기화한 데이터에 반영하지 않습니다. PC 연결 및 수집 ON/OFF 설정은 유지하며 ON이면 첫 관측 번호를 새 기준으로 수집을 이어갑니다.
- 담당 PC의 데이터를 로컬 SQLite에 유지하며 공유폴더에 SQLite를 직접 열지 않습니다. 서브 PC의 과거 독립 데이터는 자동 합산하지 않습니다.
- 이전 집계 기준, 제외 프로그램, 소재 종류, 재고, 취소, 통계, CSV, 백업, 초기화 기능은 유지했습니다.
- 정식 지후니우스 배포본은 기존 공개 업데이트 경로를 사용합니다. 별도로 전달한 검토용 파일은 공개 업데이트로 교체되지 않으므로, 검토를 마친 뒤 배포본으로 전환합니다.
- 임시 소재 보관을 지원하려면 수집 담당 PC와 입력 PC를 모두 2026.11.06.4 이상으로 업데이트합니다. 담당 PC가 구버전이면 전환 버튼은 비활성화됩니다. 데이터 형식은 v4로 이전되며 기존 기록과 재고는 유지하고 `.pre-v4.bak` 원본을 한 번 보관합니다. 구버전 수집 프로그램은 v4를 열지 못하므로 이후에도 v4 지원 버전을 사용해야 합니다.

검증: 전체 초기화·자동 백업 생략·트랜잭션 실패·재시도·초기화 이전 요청 차단·이전 통계 화면 제거를 자동 검사합니다. 실제 Windows 회사 PC, SMB 권한, 방화벽, 설비 모니터링 응답과 실제 가공 수량 대조는 현장 확인이 필요합니다.

- 2026.11.06.10: 9020은 집계하지 않으며 `6001 → 9020 → 6001`은 가공 +0, `6001 → 9020 → 6002`는 +1입니다. 기존 3999·9012·9999 이후 같은 번호 재가공은 +1을 유지합니다. 불량 입력은 양품 −1 / 불량 +1이며 전체 가공 수는 유지합니다.
- 데이터 형식 v6에는 9020 직전의 비교 번호를 호기별로 보존합니다. 기존 데이터는 `.pre-v6.bak`을 한 번 보관한 뒤 전환하며, 과거 수량은 소급 수정하지 않습니다. 수집 담당 PC를 포함해 사용하는 PC 모두 업데이트해야 새 집계 규칙이 적용됩니다.
