# 소재사용량조사(Beta)

- 지후니우스 상단 특수 돌출량 오른쪽 버튼으로 원래 크기의 팝업을 엽니다. 다시 누르거나 X를 누르면 숨깁니다.
- 메인 화면 하단에는 1~9호기가 가로로 배치되며 각 호기 아래 ‘불량 +1’과 ‘소재교체’가 있습니다. 기존 팝업의 저장·집계·동기화 경로를 사용합니다. 입력 중인 호기는 저장 결과 확인까지 잠깁니다.
- 메인·서브 모두 빠른 입력 연결을 위해 소재 프로그램을 숨김 상태로 함께 시작합니다. 수집 ON/OFF 설정은 바꾸지 않습니다. 메인 입력의 확인 대기 기록은 PC에 보관되고 재실행 시 같은 요청 번호로 확인하므로 중복 반영하지 않습니다.
- 기존 독립 소재카운터는 완전 종료한 뒤 통합 기능을 사용합니다. 배포본은 지후니우스의 기존 업데이트 경로로 설치합니다.
- 기존 소재 데이터가 있는 메인 PC에서 먼저 ‘이 PC 수집 ON’을 켭니다. 처음 ON을 켠 PC가 수집 담당으로 등록됩니다.
- 서브 PC는 OFF로 유지합니다. 같은 회사 공유 폴더의 연결 설정으로 담당 PC를 찾습니다. 별도 IP 입력은 없습니다.
- 담당 PC 및 지후니우스가 실행 중이어야 동기화합니다. 담당 PC의 팝업은 숨겨도 됩니다.
- 불량·소재교체·재고·취소는 담당 PC에서 저장 성공을 확인한 뒤 표시합니다. ‘저장 확인 대기’는 같은 작업을 다시 입력하지 않습니다.
- 연결이 끊겨 완전 종료할 때 확인 대기 입력을 유지하는 선택이 있습니다. 다음 실행에서 같은 요청 번호로 결과를 확인합니다.
- 기간 통계는 실제 조회 날짜·호기·조회 시각을 표시합니다. ‘새 기록 있음 / 조회 조건 변경’이면 다시 조회합니다.
- 현재 집계는 소재교체 버튼 하나로 통일했습니다. 중도교체 버튼과 기간 통계의 중도파기 구분은 표시하지 않습니다. 적게 가공한 봉도 교체 시 소모 1봉에 포함하며 기존 중도교체 기록도 집계에 유지합니다. 중간 시작·수집 공백·불량초과 기록의 평균 제외 기준은 유지합니다.
- ‘모두 초기화’는 확인 후 가공·불량·교체·입출고 기록, 현재 집계, 재고 수량, 호기별 소재 설정을 모두 지웁니다. 재고는 0봉이 아닌 미등록 상태가 됩니다. 사용자 요청에 따라 초기화 전 자동 백업은 하지 않습니다. 필요하면 별도의 ‘전체 데이터 백업’을 먼저 사용합니다.
- 초기화는 모든 PC에 반영되고 이전 통계·기록 화면도 비웁니다. 과거 요청이 뒤늦게 도착해도 초기화한 데이터에 반영하지 않습니다. PC 연결 및 수집 ON/OFF 설정은 유지하며 ON이면 첫 관측 번호를 새 기준으로 수집을 이어갑니다.
- 담당 PC의 데이터를 로컬 SQLite에 유지하며 공유폴더에 SQLite를 직접 열지 않습니다. 서브 PC의 과거 독립 데이터는 자동 합산하지 않습니다.
- 이전 집계 기준, 제외 프로그램, 소재 종류, 재고, 취소, 통계, CSV, 백업, 초기화 기능은 유지했습니다.
- 정식 지후니우스 배포본은 기존 공개 업데이트 경로를 사용합니다. 별도로 전달한 검토용 파일은 공개 업데이트로 교체되지 않으므로, 검토를 마친 뒤 배포본으로 전환합니다.

검증: 전체 초기화·자동 백업 생략·트랜잭션 실패·재시도·초기화 이전 요청 차단·이전 통계 화면 제거를 자동 검사합니다. 실제 Windows 회사 PC, SMB 권한, 방화벽, 설비 모니터링 응답과 실제 가공 수량 대조는 현장 확인이 필요합니다.
