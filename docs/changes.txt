소재사용량조사(Beta) 통합
- 특수 돌출량 옆에서 소재사용량조사 팝업을 열고 다시 눌러 숨길 수 있습니다. 메인 하단에는 1~9호기의 불량 +1·소재교체 버튼을 제공합니다.
- 수집 담당 PC 한 대가 데이터를 저장하며, 수집 OFF인 서브 PC의 불량·소재교체도 같은 데이터에 반영합니다. 수집 ON/OFF는 PC별로 기억하고 시작 시 복원합니다.
- 입력은 저장 결과를 확인하며, 연결 중단 후 재시도해도 같은 요청을 중복 집계하지 않습니다. 업데이트 전에는 확인 대기 입력과 저장 상태를 점검합니다.
- 기간 통계에서 봉당 양품·불량과 소모 봉 수를 확인합니다. 적게 가공한 봉도 소재교체 시 1봉에 포함하며 중도교체·중도파기 구분은 화면에서 제거했습니다.
- 모두 초기화는 확인 후 소재 관련 데이터를 삭제합니다. 초기화 전 자동 백업은 하지 않으며, 연결 설정과 수집 ON/OFF는 유지합니다.
- 메인 하단의 소재·불량 설명 및 연결 안내 문구를 제거하고 높이를 줄였습니다. 기존 MES/POP·STL·파일 변환 동작은 유지합니다.
- 업데이트·오류 기록 버튼을 탭 줄 오른쪽에 배치해 좁은 창에서도 잘리지 않도록 보정했습니다.
