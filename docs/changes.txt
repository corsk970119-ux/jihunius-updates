메인 화면 정리 · 버튼 통일 · 14파이 임시 교체
- 메인 화면의 바깥 여백, 카드 안쪽 여백과 영역 간격을 줄였습니다. 기본 창 높이를 900에서 760으로 줄이고, 글자 확대 배율에 따라 필요한 최소 높이는 확보합니다.
- 목록과 작업 기록 영역은 창 크기에 맞게 늘어나며, 하단 1~9호기의 불량·소재교체 버튼을 한 화면에서 사용하기 쉽게 배치했습니다.
- 드라이브 비우기·삭제·파일+리스트 만들기·추가·새로고침과 종료 선택창의 버튼 글자 크기·굵기·세로 여백을 통일했습니다. 상단 로고 비율도 조정했습니다.
- 인수인계·새 버전 알림의 노란색 표시와 기존 기능, 작업 처리 방식은 유지합니다.
- 소재사용량조사 현재집계에 호기별 '14파이 교체 / 원소재로 복귀' 버튼을 추가했습니다. 현재 소재를 보관하고 교대 사용하며, 돌아온 소재의 기존 양품·불량 누적을 이어갑니다.
- 처음 꺼내는 14파이 소재만 재고 1봉을 차감합니다. 보관한 원소재나 14파이를 다시 사용하면 재고를 중복 차감하지 않습니다. 새 봉으로 교체할 때는 기존 소재교체 버튼을 사용합니다.
- 소재 보관 상태는 재시작 후에도 유지되며, 다른 PC의 소재 변경과 중복 입력을 검사합니다. 종료된 봉만 봉당 통계에 반영하는 기준은 유지합니다.
- 기존 소재 데이터는 유지하여 새 형식으로 전환합니다. 수집 PC와 입력용 서브 PC를 모두 이 버전으로 업데이트해 주세요. 전환 후의 소재 데이터는 구버전에서 열 수 없습니다.
